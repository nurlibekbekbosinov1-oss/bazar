# Mal Bazar — Qaraqalpaqsha

## Isletiw
1. `pip install -r requirements.txt`
2. `python app.py`
3. Brauzerde `http://127.0.0.1:5000`
4. Admin: `/admin`
5. Admin paroli: `8310`

## Admin panel
- Daǵaza bahasın `0` etseńiz — tegin.
- Bahası 0-den úlken bolsa — pulli rejim.
- Karta nomerin qosıw.
- Daǵazalardı kóriw.
- Daǵazaǵa ruqsat beriw.
- Satılǵan daǵazanı belgilaw.
- Daǵazanı óshiriw.

## Eskertiw
Bul bastapqı isleytuǵın nusqa. Pulli tólemde chek súwretin júklew hám adminge avtomatik jetkiziw bólimi keyingi integraciya retinde qosıladı. Naqty online tólem ushın Payme/Click/Apelsin sıyaqlı tólem API-si kerek.
